# Figure Briefs｜图件任务书

These briefs are for the Final Integration / visual-production stage. They are **evidence figures**, not atmospheric hero renders. Every figure must label Official / Verified / Derived / Assumed / Unknown and must not visually promote provisional geometry into an official redline.

## F01 — Public Capability Interface: City Ability, Not AI Object

**Story:** show how ordinary public-space baseline, Ambient Layer, Consent Layer, Human Override and failure-safe mode stack together.

**Format:** technical-schematic / layered section.

**Main elements:**
- people + conventional public space largest/foreground;
- staff + ordinary infrastructure second layer;
- capability interface as a smaller layer;
- AI/data backstage as the thinnest layer;
- arrows for consent, override and fallback;
- R0–R3 legend.

**Evidence references:** `public_capability_interface.md`, `capability_catalog.md`.

**Avoid:** glowing AI core, giant screens, autonomous system visually dominating people.

## F02 — Eight-Node Public Capability Family

**Story:** one identity grammar, eight different civic jobs.

**Format:** component matrix / isometric technical catalogue.

**Show:** N1–N8 with dominant use, physical baseline, Ambient/Consent/Override status, failure-safe state.

**Inset:** component-library mapping C01–C20.

**Evidence references:** `node_typologies.md`, `component_library.md`.

**Avoid:** identical smart kiosks repeated eight times.

## F03 — 24-Hour Scenario Orchestration

**Story:** the corridor changes role by time rather than becoming a universal smart plaza.

**Format:** horizontal 24-hour timeline + five-zone bands.

**Show:** S01–S12 by hour/season, with four testing scenarios visibly bounded to declared windows; emergency layer cuts across all times.

**Evidence references:** `scenario_cards.md`, `scenario_orchestration.md`, `personas.md`.

## F05 — Landmark as Memory: 1909 → 2026 → Future → Retired

**Story:** one century-spanning learning sequence, not three isolated buildings.

**Format:** linear progression / subway-map hybrid.

**Stations:**

2. 2026 City Learning Archive — judge/modify capability;

**Evidence references:** `landmark_network.md` + four landmark/archive files.

## F07 — 2026 City Learning Archive: STOP Is Also Learning

**Story:** public evidence and governance are the landmark.

**Format:** civic interior/public-space axonometric + evidence-card close-up.

**Show:** Annual City Version Release, Evidence Tables, Modification Wall, Stop Ledger, Public Review Table, honor-display rules.

## F08 — Future Open Test Station: Reversibility as Architecture

**Story:** a test station must visibly support stop, bypass, reset and removal.

**Format:** exploded axonometric / section.

**Show:** Problem Porch, public bypass, observation edge, controlled threshold, reversible bay, manual steward point, reset yard.

**State overlay:** proposed → authorized → active → paused/stopped/completed → review.

**Avoid:** glossy “future pavilion” or unbounded robot activity.

## F09 — Retired Capability Archive Lifecycle

**Story:** technology has an accountable exit path.

**Format:** lifecycle diagram + archive-label specimen.

**Show:** retirement triggers → data deletion/retention review → artifact deactivation/reuse/recycle → public lesson card → replacement/next experiment.

**Key note:** preserve lesson, minimize personal data, do not shame.

## F10 — Four Failure-Safe Sections

**Story:** public value is proven when the smart layer fails.

**Format:** four aligned before/after sections:
- Climate Porch;
- Care Crossing;
- Reversible Test Yard;
- City Learning Archive.

**For each:** NORMAL → DEGRADED/OFF → what still works physically.

**Evidence:** `sections_and_sequences.md`.

## Graphic system shared by all figures

- Public Service Aesthetic: clear, credible, friendly, low-threshold.
- Railway DNA: parallel tracks, node, switch, mileage/version; abstract, contemporary.
- No cyberpunk/neon/clay/lego/storybook treatment.
- Do not rely on color alone; use line type, border, fill pattern, label and symbol.
- Source/status note on every figure.
- Provisional boundary/context = low-contrast dashed/annotated constraint.
- Proposed capability/node = distinct from Known/Verified existing conditions.
- Keep editable vector/text layers where production workflow allows.

## Suggested board hierarchy

- **A0 main narrative:** F04 + F05 + F07/F08 key sections.
- **A3 booklet:** F01–F10 distributed by chapter.
- **HTML:** interactive filtering may be added, but all critical text/meaning must remain available offline and without remote resources.
