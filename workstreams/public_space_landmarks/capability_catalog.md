## Common public-value evidence

Every capability should eventually be evaluated through five common floors — **safety, fairness, privacy, environment, cost** — plus scenario-specific measures. Averages are insufficient: integration should preserve subgroup outcomes, complaints, manual takeovers, failures, near misses and side effects.

## Status vocabulary

- `concept`: not deployed.
- `trial`: bounded, reversible test.
- `service`: operating under an identified steward.
- `degraded`: limited mode / fallback active.
- `retired`: removed from active service; archive record remains.

## Unknowns before spatial commitment

Exact node counts, size, operating hours, staffing, sensor/equipment specification, utility capacity, thermal targets, accessibility deficiencies and commercial-operator participation remain to be verified in later professional/site work.
