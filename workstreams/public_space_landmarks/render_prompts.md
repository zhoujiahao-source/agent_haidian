# Render Prompts｜后续图件生成提示词

These prompts are for controlled professional visualization. They intentionally avoid photorealistic claims of an approved/built scheme. Replace bracketed data placeholders only with verified integration-stage information.

## Global rendering constraints

Use a **Public Service Aesthetic**: clear, civic, trustworthy, calm, accessible, contemporary. Visual DNA comes abstractly from railway parallel tracks, station nodes, switches and mileage/version marks. Avoid cyberpunk, neon AI city, giant robot/chip/brain symbols, science-fiction spectacle, clay/lego/storybook styling and fake historic reconstruction.

Always distinguish:
- Known / Verified existing condition;
- Estimated / Assumed;
- Proposed design;
- Unknown.

If provisional geometry appears, draw it as muted dashed context with a visible label: `PROVISIONAL — NOT OFFICIAL REDLINE`.

### Prompt 01 — Public Capability Interface layered section

Create a professional urban-design technical schematic titled “Public Capability Interface / 公共能力接口”. Show a four-layer section: foreground ordinary people in a well-designed public space with continuous accessible paving, shade, seating, static wayfinding and human help; second layer conventional infrastructure and staff; third layer a small optional capability interface with Ambient and Consent thresholds; fourth/backstage layer minimal AI/data systems. Add arrows for consent, human override, manual fallback and OFF/degraded mode. Show R0–R3 risk ladder as a compact inset. AI must be visually subordinate. White/light neutral background, crisp annotation, black-white printable line hierarchy, no glowing screens.

### Prompt 02 — Eight node typologies catalogue

Create an editorial technical catalogue of eight distinct civic-space typologies: Civic Service Port, Climate Porch, Care Crossing, Memory Switch, Reversible Test Yard, Community Dock, Continuity Island, Capability Interchange. Use small axonometric/section vignettes, not identical kiosks. For each node show: main public action, non-AI baseline, Ambient/Consent badge, human override, failure-safe state. Use Open Node and paired-rail motifs consistently but vary spatial form and landscape/building context. Include component IDs C01–C20 as minimal callouts. No brands or vendor products.

### Prompt 03 — 24-hour scenario orchestration

Create a dense but legible 24-hour timeline diagram for the Jing-Zhang public capability network. Horizontal time from 06:00 to 00:30 plus emergency overlay. Vertical bands for Zhongzhiyuan, AI Origin Community, Dazhongsi, Zhongguancun Technology Service Wing and Xiaoyuehe Scenario Empowerment Wing. Plot S01–S12 with simple labels and persona icons; clearly bound S09–S12 testing scenarios to declared trial windows. Add the rule: “ordinary city → ambient → opt-in → bounded trial → public-value review”. Show morning commute, midday heat, weekend family/culture, evening business/night return, outage mode. Avoid decorative illustration; use subway-map / operations-board logic.

### Prompt 04 — East–west stitching / north–south continuity

Create an abstract urban-network plan diagram, not a GIS screenshot. A north–south Capability Backbone runs through a muted context field; multiple east–west seam-check lines connect surrounding neighborhoods/services. Place node-type symbols only as conceptual roles, not exact coordinates. Show public bypass routes around controlled tests. Use dashed low-contrast provisional site context with explicit note “exact official geometry pending”. Add callouts for accessibility, shade/rest, night connection and ordinary service access. No bridge/tunnel or road-redline engineering claim.

### Prompt 05 — Landmark time network

Create a linear progression / subway-map hybrid titled “Landmark as Memory: 1909 → 2026 → Future → Retired”. Four major stations: Railway Memory Ground — “build capability”; City Learning Archive — “judge / modify capability”; Future Open Test Station — “test unresolved problems”; Retired Capability Archive — “exit responsibly”. Loop retired lessons back to “new urban problems”. Use parallel rails, switch junctions and version/mileage markers abstractly. Make each station an inhabitable civic-space vignette, not an icon building. Calm public-institution visual language.

### Prompt 06 — 1909 Railway Memory Ground

Create a landscape/urban-design section-perspective of a proposed Railway Memory Ground in a Jing-Zhang heritage public-space context. Show an accessible everyday walking line, real/verified railway trace only where available, contemporary abstract paired-line paving where no authentic object is claimed, a shaded widened “switch” room with seating, restrained mileage/time markers and a quiet physical archive edge. Optional multilingual audio/archive layer appears as tiny secondary annotation. Do not invent a historic station or fake antique architecture. Label all interventions “conceptual / heritage verification required”.

### Prompt 07 — 2026 City Learning Archive

Create a civic public-space / archive axonometric titled “City Learning Archive 2026”. Show Annual City Version Release wall with equal columns Added, Modified, Scaled, Stopped, Retired, Unresolved; evidence tables with source/confidence and subgroup impacts; a Modification Wall; calm Stop Ledger; accessible Public Review Table with paper and human facilitation; small honor display recognizing public value and responsible stopping. AI is a backstage retrieval/summarization layer only. No trophy hall, no leaderboard, no faces/data dashboards implying surveillance.

### Prompt 08 — Future Open Test Station

Create an exploded axonometric/section of a modular Future Open Test Station. Show Problem Porch, public nonparticipant bypass, observation edge, controlled threshold, reversible test bay, named human steward/manual stop point, service access and Reset/Reuse Yard. Use modular joints and removable components to make reversibility visible. Add state labels Proposed / Authorized / Active / Paused / Stopped / Completed / Review. No static futuristic robot showcase. Ordinary public circulation stays independent.

### Prompt 09 — Retired Capability Archive

Create a dignified public archive/lifecycle diagram: active capability → retirement review triggers → data deletion/retention decision → artifact deactivation → reuse/recycle or selected safe artifact → public lesson card → replacement / next experiment. Include a specimen retirement label with capability/version, active period, public value, incidents/limitations, retirement reason, replacement, data decision, artifact status, lessons. Spatial inset shows a light, distributed archive shelf/bench rather than a dark “technology cemetery”. No sensational accident imagery.

### Prompt 10 — Failure-safe four-section comparison

Create four aligned urban-design sections: Climate Porch, Care Crossing, Reversible Test Yard, City Learning Archive. Each has two states NORMAL and DIGITAL OFF / DEGRADED. Clearly show what physical/public functions continue: shade/seating/water; accessible route/tactile cues/human help; public bypass/safe stopped equipment; physical version record/staffed review. Make the OFF state visually calm and functional, demonstrating resilience. Use monochrome-friendly diagrams with limited accent, text + symbols, no remote-tech glamour.

## Text / labeling rules

- Use Chinese + concise English title where space permits.
- Use “Proposed / Conceptual” for workstream design moves.
- Never write “approved”, “official redline”, “confirmed construction” or equivalent unless a future integration source explicitly supports it.
- Show source/date/confidence note on evidence figures.
- Do not fabricate precise dimensions, site boundaries, heritage-control lines, utilities or crowd numbers.
- Keep public figures diverse in age/ability without turning personas into demographic claims.
- Preserve editable labels/layers in the final design-production workflow where possible.
