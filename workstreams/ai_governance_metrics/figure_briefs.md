# Figure Briefs — AI Governance & Metrics

Visual direction: **Public Service Aesthetic** — clear, credible, friendly, low-barrier, technical-schematic. Use the Jing-Zhang dual-track / station / switch / milestone DNA as a subtle routing metaphor. Avoid cyberpunk neon, raw GIS screenshots and provisional boundaries styled as official redlines.

## Figure G1 — Urban Learning Protocol

**One story:** how a real public problem moves through diagnosis, risk authorisation, bounded experiment, public-value review, STOP/MODIFY/CONTINUE/SCALE, transfer/revalidation and retirement.

- Format: horizontal dual-track state machine.
- Main nodes: eligible issue, risk gate, human authorisation, experiment, public-value review, four decisions, Capability Backbone, transfer revalidation, archive.
- Human responsibility shown above each decision gate.
- Feedback/rollback rail below main flow.
- Required uncertainty label: governance proposal; institutional owner/SLAs not yet official.

## Figure G2 — Risk Authorization Matrix

**One story:** higher real-world consequence requires stronger human authority and narrower experimental freedom.

- Rows: Low / Medium / High / Not Eligible.
- Columns: data, autonomy, physical safety, rights/equity, approval, public notice, override, rollback, scale.
- Show escalation overrides separately; do not create a fake numeric “risk score.”

## Figure G3 — Urban Adaptation Rate Evidence Funnel

**One story:** UAR begins after an eligibility gate and counts meaningful public improvement, not AI activity.

- Left: raw observations/complaints/Agent signals.
- Gate: duplicate/evidence/public relevance/baseline/human owner/risk screen.
- Middle: fixed eligible-issue cohort.
- Right split: adapted -> UAR numerator; Responsible STOP -> Learning Safety; unresolved/overdue -> remains visible.
- Bottom: UAR-90 and UAR-365 proposed horizons with numerator/denominator/confidence/coverage.
- Explicit annotation: no operational percentage available yet.

## Figure G4 — Public Dashboard / Audit Layer Wireframe

**One story:** one evidence system serves public legibility and professional accountability at different disclosure depths.

- Top half Public: problem, status, risk, human owner, data category, target, subgroup result, incidents/overrides, feedback/exit.
- Bottom half Audit: provenance, versions, formulas, cohorts, logs, stop/rollback, corrections, transfer.
- Draw a privacy boundary: raw personal/sensitive data do not flow to public layer.

## Figure G5 — Capability Transfer Revalidation Network

**One story:** Capability Backbone exchanges validated capability records; it does not auto-deploy them.

- Five Learning Units as station-like nodes.
- Capability record moves with evidence envelope.
- Every cross-context route passes target baseline -> re-tier -> local authorisation -> bounded revalidation.
- Use arrows with switch symbols to show MODIFY / DO NOT TRANSFER / TRANSFER READY.
- Provisional geography, if shown at all, is low-contrast and explicitly provisional.

## Production notes

Every final figure should contain title, legend, source/evidence references, confidence/unknown note and official/provisional status when spatial data appear. The diagrams are explanatory assets; machine-readable JSON/CSV and the latest repository rules remain the auditable source of truth.
