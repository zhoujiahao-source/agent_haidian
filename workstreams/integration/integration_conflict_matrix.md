## Conflicts that require explicit final decisions

### A. Final project name

Status: **OPEN**.

Rule: only one Chinese and one English main name may remain in the formal package. Naming should be decided after checking agent.1 requirements, visual identity and spatial clarity. `Legible AI Belt` should not remain the headline unless a later evidence-based integration review proves it better communicates the City OS thesis without creating dual concepts.

### B. Capability Backbone physical definition

Status: **OPEN — MUST BECOME SPATIALLY SPECIFIC**.

Final design must define its component layers (for example public realm / slow mobility / heritage continuity / capability nodes / service infrastructure / learning display) based on real site evidence. Do not reduce it to a diagrammatic line.

### C. Urban Adaptation Rate formula

Status: **OPEN — FORMULA REQUIRED BEFORE FORMAL METRIC ENTRY**.

Must distinguish current observed value from proposed future monitoring. No invented value.

### D. Three-area / two-wing geometry

Status: **OPEN — EVIDENCE / OFFICIAL GEOMETRY DEPENDENT**.

Do not infer exact official polygons from approximate diagrams.

### E. Public institution/operator naming

Status: **OPEN — KEEP GENERIC UNLESS VERIFIED**.

`Public Stewardship` is a proposed governance model. Do not imply a named government body has agreed to operate it.

### F. Retired Capability Archive final Chinese naming

Status: **OPEN**.

Prefer a serious public-institution name such as `城市能力退役档案` in formal output; `城市能力墓园` may remain an internal provocative design label only if appropriate.

## Conflict resolution rule

When a creative choice conflicts with a source / schema / official task, preserve the hard rule and rewrite the creative choice. When two creative modules conflict, prefer the option that is:

1. more spatially explicit;
2. more measurable;
3. more reversible and governable;
4. more directly tied to public value;
5. more specific to Jing-Zhang rather than generic AI urbanism;
6. more reproducible from public evidence;
7. easier to communicate through the required formal package.
