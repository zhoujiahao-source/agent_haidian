# Figure Style Guide

This guide applies to all core figures and any replacement assets generated by Integration.

## 1. Five required core figures

### `site-overview.png`

One story: **Capability Backbone links differentiated learning units; provisional boundary remains a quiet constraint.**

Must show:

- north arrow / scale only when spatially meaningful;
- three areas + two wings labels;
- backbone/node hierarchy;
- provisional boundary status;
- 2–4 key callouts;
- source note.

### `land-use-structure.png`

One story: **existing city fabric remains primary context while proposed capability/service layers organize exchange.**

Must separate existing/known land context from proposed non-statutory program logic.

### `key-areas.png`

One story: **three key areas have different primary capabilities.**

Use consistent callout modules for 众智园 / AI 原点社区 / 大钟寺; add the two wings as exchange/context, not three identical colored blobs.

### `mobility-bluegreen.png`

One story: **movement, public space and blue-green continuity support everyday public capability interfaces.**

Do not imply new rail/road alignments unless supported by machine-readable proposal geometry and status labels.

### `metrics-evidence.png`

One story: **public value is auditable and uncertainty remains visible.**

Show Urban Adaptation Rate as a formula/process with denominator, failure/STOP learning and anti-gaming dimensions; include evidence-status examples.

## 2. Figure anatomy

- conclusion title: max 18 Chinese characters or concise English equivalent when possible;
- main graphic: 65–78% of canvas;
- annotations: 2–4;
- legend: only relevant subset;
- source/status footer: 8–12% of canvas;
- no decorative full-bleed render behind cartographic evidence.

## 3. Legend grouping

Use separate legend boxes/rows:

- `现状 / 提议`;
- `证据状态`;
- `能力节点 / 流`;
- `实验 / 风险`.

Do not place all possible symbols in every figure.

## 4. Provisional geometry

Render with long-dash neutral stroke, low contrast and explicit wording. Never use saturated red or thick official-looking border.

## 5. Raster export

- minimum 2400 px long edge for report figures;
- preferred 300 dpi at intended print size for board placement;
- PNG for line/flat information graphics; SVG retained as source when possible;
- test grayscale and 100% zoom label readability.

## 6. Vector/PDF

Where toolchain permits, keep map/diagram text and lines vector in A0/A3 PDF rather than rasterizing the entire board.

## 7. Image-generation prompts

If render prompts are used, they must request real public-space design, ordinary daylight/night accessibility, subtle infrastructure integration, people using public services and visible human override / signage. Explicitly exclude cyberpunk neon, hologram city, giant robot/AI face, sci-fi megastructure and unsupported site-specific geometry.
