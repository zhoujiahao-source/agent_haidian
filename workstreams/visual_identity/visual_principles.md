# Visual Principles — Public Service Aesthetic

## Intent

The identity must feel like public infrastructure: clear, stable, legible, accountable and durable. It should not look like a startup pitch deck, entertainment IP, cyberpunk city or AI gadget brand.

## 1. Five principles

1. **Evidence before atmosphere** — every core figure starts from a claim, evidence layer and status note; hero imagery never substitutes for spatial proof.
2. **Open before iconic** — marks, nodes and diagrams should visually show access, exchange, continuation and human entry rather than a sealed emblem.
3. **State is semantic** — evidence status, design status, experiment state and risk are four separate systems; do not collapse them into one red/amber/green palette.
4. **Redundancy for accessibility** — encode critical differences with at least two channels among text, icon, border, line pattern, hatch and color.
5. **One system across scales** — A0, A3, HTML, five core figures, scenario cards and dashboard use the same spacing, typography, legend logic and token names.

## 2. Railway DNA translation

- double track → parallel information/capability flows;
- station → capability node / public interface;
- switch → route choice / authorization / exchange;
- milepost → year / version / release marker;
- timetable logic → staged capability release and review cadence.

Forbidden literal nostalgia: steam locomotive silhouette, vintage tickets, faux brass plates, retro station signage, heritage-themed serif display as the primary system.

## 3. Grid

### A0 landscape

- page: 1189 × 841 mm;
- outer safe margin: 24 mm minimum;
- 12 columns;
- gutter: 8 mm;
- baseline increment: 4 mm;
- major modules should occupy 3, 4, 6, 8 or 12 columns;
- no core body copy below 16 pt at final print size.

### A3 landscape

- page: 420 × 297 mm;
- outer safe margin: 14 mm;
- 12 columns;
- gutter: 4 mm;
- baseline increment: 3 mm;
- body copy target: 9.5–11 pt;
- map labels target: 8.5 pt minimum unless cartographically unavoidable.

### HTML / report

- content max-width: 1440 px for visual dashboard; 920 px for long-form report text;
- 12-column responsive grid;
- spacing unit: 4 px;
- default section vertical rhythm: 48/64/96 px depending hierarchy;
- evidence panels use a stable 320 px minimum card width rather than arbitrary masonry.

## 4. Hierarchy

Each core figure should contain, in order:

1. one-sentence conclusion title;
2. primary map/diagram;
3. 2–4 numbered callouts;
4. only the relevant legend subset;
5. evidence/provisional status note;
6. source / metric identifiers.

Do not use giant slogans to consume the board. The title should state a finding or design action, not a mood.

## 5. Stroke system

Nominal print stroke classes:

- hairline/reference: 0.18 mm;
- secondary boundary: 0.25 mm;
- ordinary feature: 0.35 mm;
- primary structure: 0.55 mm;
- capability backbone: 0.80 mm;
- selected/active emphasis: 1.10 mm.

Never use sub-0.15 mm essential information on final PDF.

## 6. Shape language

- base geometry: circles, open rings, parallel lines, switch-like forks, rectangular evidence tags;
- corner radius: 2–4 mm in print / 6–12 px on web;
- avoid pill-shaped everything; reserve pills for status tags;
- avoid glossy 3D, glassmorphism and neon glows.
