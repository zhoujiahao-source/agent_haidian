# Assets Drafts

These files are **design-source drafts**, not canonical final submission assets.

- `open-node-family-a.svg` — recommended primary Open Ring Switch mark.
- `open-node-family-b.svg` — interchange/network secondary glyph.
- `open-node-family-c.svg` — version/milepost secondary mark.

Integration may redraw/optically correct these while preserving the documented geometry and semantics. Never treat this directory as evidence or official branding approval.
