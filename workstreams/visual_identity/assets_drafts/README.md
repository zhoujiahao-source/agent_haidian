# Assets Drafts

These files are **design-source / QA / integration-candidate assets**, not canonical final submission assets.

## Identity

- `open-node-family-a.svg` — recommended primary Open Ring Switch mark; use at ≥32 px digital and ≥4 mm print after production proof.
- `open-node-family-a-micro.svg` — optically simplified small-size variant; use at ≤24 px digital.
- `open-node-family-b.svg` — interchange/network secondary glyph.
- `open-node-family-c.svg` — version/milepost secondary mark.

These PNGs are test/export assets, not substitutes for the vector masters.

## Information design

- `design_tokens.css` — reusable color, spacing, evidence/design/experiment/risk, map and version tokens for offline HTML and figure-generation scripts.
- `state-legend.svg` — complete monochrome-first legend covering Official/Verified/Derived/Assumed/Unknown; Known/Estimated/Proposed/Unknown; TEST/STOP/MODIFY/CONTINUE/SCALE; and R1/R2/R3.
- `specimen.html` — offline visual-system specimen using local assets only.
- `asset_manifest.json` — machine-readable asset roles/status.

Integration may redraw or further optically correct these while preserving the documented semantics. Never treat this directory as evidence, official branding approval or an official planning layer.
