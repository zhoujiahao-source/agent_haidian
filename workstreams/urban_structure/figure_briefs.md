# Figure Briefs — Final Integration / Visual Team

These briefs translate the Urban Structure workstream into the five core evidence figures required by the submission workflow. They are **design briefs**, not finished figures.

## FIG-01 — Site Overview / 城市能力交换网络总览

### One story

**The Jing-Zhang corridor is a six-layer Capability Backbone connecting five differentiated learning units, not a homogeneous AI park or a single technology boulevard.**

### Must show

- overall provisional study/design boundary as low-contrast dashed context;
- candidate Backbone as a layered armature, not one thick line;
- Three Areas + Two Wings with five distinct capability labels;
- seven node prototype icons in a legend, but only evidence-backed / candidate anchors placed on the map;
- north-south five-segment sequence;
- east-west axes shown as `study only` unless later verified;
- one small City OS learning loop: problem → authorization → pilot → public-value review → STOP/MODIFY/CONTINUE/SCALE → exchange/revalidation → memory/retirement.

### Avoid

- raw GIS screenshot;
- equal-weight layer dump;
- treating provisional rectangles as official boundaries;
- cyberpunk/AI-network glow.

### Annotation

`Boundary status: provisional constraint; official polygon not yet supplied.`

## FIG-03 — Key Areas / 三区重点深化

### One story

**The three key areas share City OS governance but have deliberately different urban forms, dominant nodes and public-risk questions.**

### Layout

Three equal-status insets, not one repeated template:

1. Zhongzhiyuan: public edge → observation buffer → controlled test area → shared research frontage.
2. AI Origin: accessible neighborhood route → shade/interface → civic room → ordinary frontage → removable pilot.
3. Dazhongsi: transit/public movement → market/night spill-out → service/recovery bay → active frontage.

### Must include

- a section sketch for each inset;
- dominant node types;
- Ambient / Consent / Human Override labels;
- Permanent / Adaptive / Experimental legend;
- conceptual dimension ranges clearly marked `design envelope, not surveyed dimension`.

### One story

**Success is measured by public-value learning and evidence quality, not AI deployment count or falsely precise site metrics.**

### Must show

- STOP / MODIFY / CONTINUE / SCALE funnel;

  - 6 Backbone layers;
  - 5 differentiated learning units;
  - 7 node prototypes;
  - 5 candidate node anchors;
  - 5 current east-west study axes;
  - 7 section briefs.
- an `Unknown` panel: official polygons, FAR, height, density, green ratio, setbacks, road redlines, ownership, complete buildings, heritage GIS, utilities.

### Do not show

- a fake Urban Adaptation Rate percentage;
- provisional geometry-derived area as official precision.

## Common figure grammar

Every core figure should include:

1. title + one-sentence finding;
2. legend;
3. source/status note;
4. `Official / Verified / Derived / Assumed / Unknown` where facts are used;
5. `Known / Estimated / Proposed / Unknown` for drawing status;
6. a visible provisional-boundary disclaimer;
7. references to the corresponding workstream file / candidate GeoJSON;
8. high-contrast design conclusion and low-contrast provisional/background geometry.

Recommended visual direction remains technical-schematic / subway-map / information-design rather than entertainment rendering.
