# Final Integration Checklist — Urban Structure

This checklist is for the Final Integration Agent. It does **not** authorize this workstream to edit canonical submission geometry.

## Before adopting geometry
- [ ] Re-read latest upstream Skill and required inputs.
- [ ] Check whether trusted official SITE_BOUNDARY / KEY_AREA appeared.
- [ ] Verify every east-west stitch against crossing, public/legal access, accessibility, heritage, municipal and safety evidence.
- [ ] Verify every node host against ownership/use, public access, fire, heritage, utilities, maintenance and stewardship.
- [ ] Keep unsupported nodes/links Unknown.

## Capability Backbone
- [ ] Show six distinguishable layers: memory, access, public realm, blue-green, nodes, operations.
- [ ] Do not render it as one thick decorative corridor.
- [ ] Preserve light-touch segments and non-digital access.
- [ ] Use at least three representative sections.
- [ ] Show differentiated Three Areas / Two Wings exchange.

## Three Areas / Two Wings
- [ ] Zhongzhiyuan = porous verification campus.
- [ ] AI Origin = distributed learning neighborhood.
- [ ] Dazhongsi = transit-market-service commons.
- [ ] Zhongguancun Wing = professional exchange interface.
- [ ] Xiaoyuehe Wing = blue-green/public-life test field.

## Node and risk logic
- [ ] Select N1–N7 only where need + host + stewardship intersect.
- [ ] Essential services retain analog/human fallback.
- [ ] Personalized/recognition functions use Consent Layer.
- [ ] Experimental nodes have operator, stop, fallback, time window, restoration and review.
- [ ] Memory nodes show STOP/MODIFY/RETIRE as well as success.

## Permanent / Adaptive / Experimental
- [ ] Permanent elements pass AI-off test.
- [ ] Adaptive elements change without rebuilding core infrastructure.
- [ ] Experimental elements are reversible.
- [ ] Prefer component-level phase attributes over coarse site-wide phase polygons.

## Drawing language
- [ ] Provisional geometry dashed/low-contrast/labeled.
- [ ] Known/Estimated/Proposed/Unknown use symbols and labels, not color alone.
- [ ] Section dimensions labeled conceptual envelopes.
- [ ] Core figures include title, legend, source, evidence status and annotations.

## Canonical checks after adoption
- [ ] Update geometry, then metrics, matrices, assumptions, sources and manifest.
- [ ] Align narrative/figures with machine-readable data.
- [ ] Render HTML, finalize, run self-check and participant preflight `--check-push`.
- [ ] Repair until actual PASS; never claim PASS before commands succeed.
