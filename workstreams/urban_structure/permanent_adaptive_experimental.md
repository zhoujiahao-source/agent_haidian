# Permanent / Adaptive / Experimental — Reversible Urban Learning Layers

## 1. Why three layers

A city that “learns” should not make every experiment permanent. The spatial system therefore separates long-life public value from changeable programs and time-limited tests.

This is a design framework, not an investment schedule or approval sequence.

## 2. Permanent Infrastructure / 永久基础层

### Purpose

Build the no-regret public foundation that remains valuable even if today's AI technology becomes obsolete.

### Candidate elements

- verified accessible walking / cycling connections;
- safe crossings and barrier-free approaches once confirmed feasible;
- shade, seating, lighting, drainage, toilets/water where programmatically appropriate;
- durable blue-green ecological structure;
- public-space and ground-floor civic interfaces;
- physical wayfinding and analog information;
- basic power/data-ready conduits only where professionally justified, without locking into a specific vendor/model;
- human-help / stewardship spaces;
- durable memory/archive locations.

### Design rule

Every Permanent element must pass the **AI-off test**: it should still provide clear public value if all AI systems are removed.

## 3. Adaptive Layer / 适应层

### Purpose

Allow the corridor to change with seasons, community needs, annual programming and evaluated capability updates without rebuilding the basic city.

### Candidate elements

- modular shade/furniture and event equipment;
- changeable civic/service-room fit-out;
- rotating market/service bays;
- seasonally adjusted route/event management;
- City Version Release exhibitions;
- temporary programming for developer/community clinics;
- configurable but non-structural observation / demo elements;
- changeable signs and public information that expose capability status.

### Design rule

Adaptive components should be replaceable without removing the Permanent carrier. Their operator, maintenance burden and storage should be identified before adoption.

## 4. Experimental Layer / 实验层

### Purpose

Host small, reversible and measurable trials under explicit authorization.

### Candidate elements

- removable AI/service kiosks;
- controlled robotics / low-speed test zones where legally and physically suitable;
- temporary environmental or accessibility prototypes;
- reversible queue/market/service configurations;
- time-limited sensing using public/aggregate/minimum-necessary data;
- temporary test furniture / markings / observation points.

### Required lifecycle

Every experimental component must specify:

1. problem statement;
2. affected users;
3. risk tier and authorization owner;
4. start/end window;
5. physical boundary;
6. data/consent boundary;
7. human override / shutdown;
8. public-value metrics;
9. complaint / incident pathway;
10. STOP / MODIFY / CONTINUE / SCALE decision;
11. removal / restoration plan;
12. archive record if retired.

## 5. Layer interaction matrix

| Urban element | Permanent | Adaptive | Experimental |
|---|---|---|---|
| Backbone route | verified accessible path / crossing | event routing / seasonal management | temporary demand test only |
| Public space | shade, seating, drainage, universal design | modular furniture / markets / exhibits | prototype kiosk/service bay |
| Building edge | civic/service-ready frontage | reconfigurable rooms | time-limited lab/demo/service module |
| Blue-green system | ecology, soil, shade, water-sensitive structure | seasonal management | climate/service pilot |
| Information | physical wayfinding + human service | changeable version/status display | pilot-specific explanation/consent interface |
| Memory | durable city-learning archive location | rotating annual release | temporary failure/experiment display |

## 6. Phase logic

### Phase A — Evidence + no-regret public value

Before major capital work: verify crossings, accessibility, heritage constraints, public-space hosts and operations. Implement only low-cost/high-public-value improvements that do not require invented statutory controls.

### Phase B — Adaptive node network

After host sites and stewardship are verified: strengthen neighborhood interfaces, professional exchange interfaces, learning-unit public edges, event-ready spaces and blue-green public capability interfaces.

### Phase C — Selective permanent upgrades

Only where evidence demonstrates sustained need and feasibility: deepen structural crossings, long-life civic rooms, landscape/ecological infrastructure and other public facilities.

### Continuous experimental cycle

Experiments can occur during all phases only when risk, permission and reversibility are appropriate. A pilot's success does not automatically justify permanent construction.

## 7. Graphic convention recommendation

Final drawings should distinguish the three layers using more than color:

- Permanent: solid edge / continuous line / durable hatch.
- Adaptive: segmented edge / medium-opacity hatch / modular icon.
- Experimental: dotted outline / time-window tag / reversible symbol.

This remains legible in grayscale and avoids confusing proposal status with certainty status.

## Phase 6 conclusion

The city-learning concept is now spatially reversible: the long-life investment is public access/ecology/stewardship; changeable programs sit on top; high-uncertainty AI tests remain removable and accountable.
