# Node Hierarchy — Public Capability Interface Network

## Important status note

All size and catchment ranges below are **conceptual urban-design envelopes**, not approved construction scales or statutory service radii. Exact siting requires verified base data, ownership, accessibility, heritage, municipal, fire and operating review.

## Hierarchy summary

| Type | Typical conceptual catchment | Conceptual physical envelope | Main role |
|---|---:|---:|---|
| N1 Backbone Exchange Hub | 800–1500 m | 800–3000 sqm mixed indoor/outdoor | network-scale capability exchange + public review |
| N2 District Learning Node | 400–800 m | 300–1500 sqm | district production/validation/interface |
| N3 Neighborhood Interface | 150–400 m | 30–300 sqm | daily public capability access + human help |
| N4 Experimental Node | 50–200 m controlled zone | 50–500 sqm | reversible, time-limited pilot |
| N5 Memory / Retirement Node | corridor/destination based | 100–1000 sqm | learning archive, failure/retirement memory |
| N6 Professional Exchange Node | 300–800 m | 100–800 sqm | IP/legal/standard/capital/service exchange |
| N7 Blue-Green Capability Interface | 200–500 m | 100–1000 sqm landscape-led | climate/public-space capability testing |

## N1 — Backbone Exchange Hub / 骨干交换枢纽

- `node_id`: US-N1
- `level`: network
- `host_area`: candidate central exchange location; exact site Unknown
- `main_capability`: capability discovery, routing, public review and annual version release
- `secondary_capability`: culture/memory, cross-unit coordination
- `target_users`: residents, researchers, developers, public institutions, service organizations, visitors
- `physical_elements`: civic room, public forum, accessible plaza, human help desk, version/archive display, branch wayfinding
- `digital/AI layer`: public status board, capability catalogue, non-personal network information
- `ambient_functions`: public information, environmental comfort status, event information
- `consent_functions`: any personalized service or account-based interaction
- `human_override`: staffed help / escalation during operation; emergency/manual shutdown for pilots
- `risk_tier`: low–medium as a place; individual services assessed separately
- `layer`: primarily Permanent + Adaptive
- `evidence_basis`: City OS constitution + taskbook; exact site is Proposed/Unknown
- `unknowns`: site, ownership, building reuse, staffing, municipal capacity

## N2 — District Learning Node / 片区学习节点

- `node_id`: US-N2
- `level`: district
- `host_area`: one or more in each Three Areas learning unit
- `main_capability`: district-specific production/validation
- `secondary_capability`: public observation/feedback
- `target_users`: district users plus professional teams and nearby public
- `physical_elements`: shared room/courtyard, observation edge, service desk, meeting/review room
- `digital/AI layer`: experiment/service status, documentation, safe test interface
- `ambient_functions`: general public information and low-risk environment support
- `consent_functions`: participation, personalized service, recognition/recommendation
- `human_override`: named operating steward and on-site/remote manual stop where relevant
- `risk_tier`: low–high depending on hosted pilot; high-risk pilots require stricter authorization outside normal public flow
- `layer`: Permanent carrier + Adaptive fit-out + Experimental modules
- `evidence_basis`: official unit role + design constitution
- `unknowns`: host building/parcel, access and safety capacity

## N3 — Neighborhood Interface / 社区公共能力接口

- `node_id`: US-N3
- `level`: neighborhood
- `host_area`: community streets, transit interfaces, park/service entrances; exact sites to verify
- `main_capability`: simple access to navigation, accessibility, community and emergency-related capabilities
- `secondary_capability`: feedback, human service recovery
- `target_users`: everyone, with explicit design for older people, children, disabled users and non-smartphone users
- `physical_elements`: shade/seating, tactile/visual information, small staffed or shared service point, analog map, charging where feasible
- `digital/AI layer`: optional service kiosk / QR / voice or accessible interface
- `ambient_functions`: non-personal local information
- `consent_functions`: personalized advice or account-based service
- `human_override`: visible human contact / phone / staffed route; essential service never digital-only
- `risk_tier`: low–medium
- `layer`: Permanent + Adaptive
- `evidence_basis`: Public Capability Interface constitution
- `unknowns`: operating partner, detailed accessibility audit

## N4 — Experimental Node / 可逆实验节点

- `node_id`: US-N4
- `level`: controlled pilot
- `host_area`: Zhongzhiyuan test areas, Xiaoyuehe public-space pilots, selected Dazhongsi service prototypes; exact sites to verify
- `main_capability`: small-scale reversible testing
- `secondary_capability`: public observation and evidence collection
- `target_users`: opted-in participants / affected public as appropriate, operators, evaluators
- `physical_elements`: removable boundary/marking, prototype device or service bay, observation point, clear status/exit signage
- `digital/AI layer`: pilot-specific
- `ambient_functions`: only if low-risk and non-personal
- `consent_functions`: mandatory for personal/recognition/personalized components
- `human_override`: immediate stop, fallback procedure, responsible operator
- `risk_tier`: variable; authorization scales with impact
- `layer`: Experimental
- `evidence_basis`: reversible-learning constitution / 100-day-pilot asset
- `unknowns`: pilot-specific legality, engineering and safety review

## N5 — Memory / Retirement Node / 城市学习记忆节点

- `node_id`: US-N5
- `level`: network/district memory
- `host_area`: railway-heritage-related public spaces or key public destinations after heritage/site verification
- `main_capability`: record city learning, including STOP/MODIFY/RETIRE outcomes
- `secondary_capability`: culture, public education, contributor recognition
- `target_users`: public, students, visitors, professionals
- `physical_elements`: durable archive element, timeline, physical artifacts where lawful, quiet reflection space
- `digital/AI layer`: optional searchable public archive
- `ambient_functions`: public non-personal interpretation
- `consent_functions`: optional account/bookmark functions only
- `human_override`: curatorial/public stewardship
- `risk_tier`: low
- `layer`: Permanent + Adaptive exhibition
- `evidence_basis`: Landmark as Memory / Retired Capability Archive constitution
- `unknowns`: heritage permissions, archive stewardship and artifact rights

## N6 — Professional Exchange Node / 专业服务交换节点

- `node_id`: US-N6
- `level`: wing/network support
- `host_area`: Zhongguancun Technology Service Wing interfaces
- `main_capability`: IP, legal, standard, capital and professional-service routing
- `secondary_capability`: partnership / international collaboration
- `target_users`: research teams, startups, institutions, professional services
- `physical_elements`: service desk, consultation room, review/demo room, meeting space
- `digital/AI layer`: service routing and public resource catalogue
- `ambient_functions`: resource information
- `consent_functions`: organization/user-specific advisory workflows
- `human_override`: licensed/responsible professionals retain final judgment
- `risk_tier`: medium depending on service
- `layer`: Permanent + Adaptive
- `evidence_basis`: official wing role + taskbook
- `unknowns`: specific providers and operating model

## N7 — Blue-Green Capability Interface / 蓝绿公共能力接口

- `node_id`: US-N7
- `level`: landscape/public-space
- `host_area`: Xiaoyuehe-related public-space test locations after verified geometry
- `main_capability`: climate comfort, accessible public life, maintenance/resilience learning
- `secondary_capability`: recreation, health, education
- `target_users`: park/public-space users and maintenance teams
- `physical_elements`: shade, seating, accessible path, planting/water-sensitive elements, analog refuge, removable test point
- `digital/AI layer`: optional aggregate environmental sensing / advisory
- `ambient_functions`: low-risk public environmental information
- `consent_functions`: any individualized recommendation/account function
- `human_override`: manual maintenance / service route; non-digital signage
- `risk_tier`: low–medium
- `layer`: Permanent ecological carrier + Adaptive + Experimental
- `evidence_basis`: official wing role + public-value constitution
- `unknowns`: water/park boundary, ecology/hydrology and maintenance authority

## Node spacing principle

Do not distribute nodes at equal geometric intervals. Place them where **public life + capability need + physical host + stewardship** intersect. A gap is preferable to a fictitious node if the host condition is Unknown.

## Phase 5 conclusion

The node system now has seven prototypes with clear users, physical hosts, AI layers, consent boundaries, human override, risk logic and reversible status. The Final Integration Agent can select only those supported by site evidence rather than filling the map with repeated icons.
