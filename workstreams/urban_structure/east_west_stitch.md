# East-West Stitch Strategy

## 1. Principle

East-west stitching is a **barrier-resolution program**, not a promise to build five new crossings. The existing submission contains five conceptual cross axes (`ROAD-002`–`ROAD-006`), but current repository evidence does not prove that any one of them is an existing legal passage, a feasible new crossing, or a priority engineering project.

Therefore this workstream separates **need**, **evidence**, and **intervention level**.

## 2. Breakpoint classification

### Class A — Must Improve

Use only when verified evidence shows that a barrier materially blocks essential public access between major destinations / neighborhoods / transit and the Backbone, and a reasonable intervention path exists.

Evidence required before final classification:

- verified existing road/rail/water geometry;
- accessible pedestrian route audit;
- public right-of-way / passage status or equivalent cleared basis;
- transit and major destination relationship;
- basic safety / engineering feasibility screen.

### Class B — Can Improve

Use where a route already exists but is uncomfortable, indirect, confusing, inaccessible, inactive or weakly connected to public space. Typical actions can be low-cost: crossings, shade, seating, wayfinding, frontage activation, universal-access repair, pocket spaces or time-based management.

### Class C — Concept Study Only

Use where the need is plausible but crossing feasibility, ownership, heritage, municipal or engineering constraints are unknown. Concept diagrams may show the desired relationship, but the line must be dashed and labeled `study only`.

## 4. Three intervention families

### 4.1 Structural Stitch

Use only after evidence confirms an existing or feasible major public connection.

**Spatial kit:** accessible crossing or passage, continuous sidewalk/path, lighting, drainage, clear sightlines, emergency/service compatibility, transit transfer clarity, protected conflict points.

**AI role:** minimal. Accessibility/navigation assistance may be layered on top, but basic passage cannot depend on AI.

### 4.2 Public-Space Stitch

For existing connections that need to become understandable and comfortable.

**Spatial kit:** corner plazas, active ground floors, shaded rest points, small civic/service rooms, tactile/visual wayfinding, bicycle parking, safe waiting, short-route markers.

**AI role:** public capability interfaces for navigation, language/accessibility help, event information or service connection; digital use optional.

### 4.3 Experimental Stitch

For testing demand or operating patterns with reversible measures.

**Spatial kit:** temporary seating, paint/marking where lawful, removable shade, pop-up service point, event-time route management, observation count points.

**AI role:** only low-risk/public/aggregate analysis; no default individual tracking. Pilot ends with STOP / MODIFY / CONTINUE / SCALE.

## 5. Stitch design sequence

For each candidate crossing, the Final Integration Agent should require a one-page evidence card:

1. barrier type;
2. existing legal/physical crossing status;
3. who is currently disadvantaged;
4. accessible detour condition;
5. nearby transit/public facility relationship;
6. heritage / water / municipal / ownership constraints;
7. proposed intervention family;
8. permanent/adaptive/experimental components;
9. human-safety responsibility;
10. evidence status and Unknowns.

Only after this card is complete should a candidate be promoted from Class C to B or A.

## Phase 3 conclusion

The immediate design output is not “five new bridges”. It is a **verification-first stitch protocol** that can turn only evidence-backed gaps into structural projects while still allowing low-cost public-space improvements and reversible experiments elsewhere.
