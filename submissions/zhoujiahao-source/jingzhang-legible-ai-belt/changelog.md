# 方案迭代记录

## v0.2 - 2026-08-08

### 总概念
- 主名称由“京张·可读AI城市带”升级为 **京张·城市能力交换带 / Jing-Zhang Urban Capability Exchange**。
- `Legible AI / 可读 AI` 保留为治理和信息设计子原则。
- 总逻辑统一为 **City OS → Public Value → Urban Learning → Capability Exchange → Public Memory → Next Version**。

### 空间
- 主轴升级为六层 Capability Backbone：历史记忆、慢行可达、公共空间、蓝绿生态、能力节点、事件运营。
- 三区两翼改为五个差异化 Learning Units，而不是重复 AI 园区。
- 引入 Permanent / Adaptive / Experimental 三层，支持 STOP、MODIFY、撤除和替换。
- 现有 ROAD / BUILDING / GREEN / PUBLIC_SPACE / PHASE 继续明确为概念设计载体，不升级为现状、法定或工程事实。

### AI 治理与公共空间
- 建立 Public Capability Interface：Non-AI Baseline、Ambient、Consent、Human Override、Failure-Safe、Public Learning Record。
- 建立 Problem Track + Capability Track、Eligible Issue Gate、风险授权与 STOP/MODIFY/CONTINUE/SCALE/TRANSFER/RETIRE 生命周期。
- 人物画像增至 8 类；场景保持 12 个，其中 4 个 testing/validation。
- 地标升级为 1909 Railway Memory Ground → 2026 City Learning Archive → Future Open Test Station → Retired Capability Archive。

### 指标
- 新增 Urban Adaptation Rate（UAR-90/UAR-365）作为旗舰指标。
- Responsible STOP 作为成功学习结果单独披露，但不虚增 UAR。
- UAR、公共价值底线、人工接管、跨区复核等运行指标均保持 `unknown/null`，直到真实 registry 存在。

### 证据与长期运营
- 增补众智园、大钟寺、AI 原点社区、小月河和京张铁路遗址公园的 2026/2025 公开背景来源，并逐条写明禁止用途。
- 引入 OSM/Overpass 与 Microsoft Global ML Building Footprints 作为 Derived basemap 候选，保留 ODbL / CDLA-Permissive-2.0 条件。
- 长期治理采用 Public Stewardship；年度公共结算点为 Jing-Zhang City Learning Assembly + Annual City Version Release。
- 二十年长期遗产定义为 Urban Capability Exchange Network，而不是固定 AI 技术栈。
