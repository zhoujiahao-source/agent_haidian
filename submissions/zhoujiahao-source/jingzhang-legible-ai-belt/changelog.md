# Changelog — Jing-Zhang Urban Capability Exchange

## v0.2-integration — 2026-08-08

### Concept integration

- Promoted the master concept from **Jing-Zhang Legible AI Belt** to **京张·城市能力交换带 / Jing-Zhang Urban Capability Exchange**.
- Retained **Legible AI** as a governance and information-design sub-principle rather than the master proposition.
- Defined the long-term city model as **City OS → Public Value → Urban Learning → Capability Exchange → Public Memory → Next Version**.

### Spatial system

- Reframed the main spine as a six-layer **Capability Backbone**: memory, access, public realm, blue-green ecology, capability nodes, and operations/events.
- Differentiated the Three Areas / Two Wings as five Learning Units rather than repeated AI districts.
- Added Permanent / Adaptive / Experimental implementation logic so real-world tests can be stopped, modified, removed, or replaced.
- Kept existing road/public-space geometry explicitly conceptual/provisional; no new crossing, redline, ownership, demolition or statutory-control claim was introduced.

### Public space and landmarks

- Adopted **Public Capability Interface** with Non-AI Baseline, Ambient Layer, Consent Layer, Human Override, Failure-Safe Mode and Public Learning Record.
- Expanded to eight node typologies and eight personas.
- Integrated 12 governed scenarios, including four testing/validation scenarios.
- Reframed landmark sequence as **1909 Railway Memory Ground → 2026 City Learning Archive → Future Open Test Station → Retired Capability Archive**.

### Governance and metrics

- Added Problem Track + Capability Track behind one public-value and risk gate.
- Added Low / Medium / High consequence-based authorization logic.
- Defined STOP / MODIFY / CONTINUE / SCALE / TRANSFER / RETIRE lifecycle semantics.
- Added **Urban Adaptation Rate (UAR-90 / UAR-365)** as the flagship outcome metric.
- Kept all operational governance metrics `unknown/null` because no live issue/experiment/outcome registry exists.
- Kept Responsible STOP as a public-learning outcome without inflating UAR.
- Added Non-AI / human alternative as a baseline public-service requirement.

### Evidence and uncertainty

- Added verified/background 2026 public sources for Zhongzhiyuan, Dazhongsi, AI Origin Community, Xiaoyuehe and Jing-Zhang Railway Heritage Park.
- Added OSM/Overpass and Microsoft Global ML Building Footprints only as open-data / Derived basemap candidates with explicit license and prohibited-use notes.
- Expanded assumptions to cover UAR, institutional responsibility, non-AI parity and evidence promotion.
- Separated official textual area references from provisional geometry-derived measurements.

### Long-term operations

- Adopted **Public Stewardship**: public institutions retain final accountability while universities, companies, developers, communities and citizens participate.
- Adopted annual **Jing-Zhang City Learning Assembly** centered on **Annual City Version Release**.
- Added Added / Modified / Scaled / Responsible STOP / Retired / Suspended / Unresolved release classes.
- Defined the 20-year inherited asset as the **Urban Capability Exchange Network**, not a fixed AI technology stack.

- Formal render/finalize/self-check/participant-preflight has **not yet been claimed** for this integrated revision.
